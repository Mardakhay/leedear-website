# Leedear

Leedear is a static, frontend-only jewelry website built as a refined editorial showcase rather than a conventional ecommerce template. The site presents the brand through a calm visual system, large typography, muted neutral surfaces, and spacious layouts inspired by a luxury catalog experience.

## Project overview

The project includes three pages:

- `index.html` — home page with the hero section, featured pieces, brand philosophy, and a spotlight gift-set block.
- `shop.html` — collection page with a curated product grid and a spotlight section.
- `about.html` — brand story page with philosophy, studio narrative, and manifesto content.

The site is styled with a single shared stylesheet and a small JavaScript file for shared page behavior.

## Features

- Fixed translucent navigation with active page highlighting
- Responsive editorial layout
- Serif/sans-serif typographic pairing
- Neutral placeholder visuals designed to feel intentional
- Featured product cards and collection cards
- Mobile bottom navigation
- Smooth fade-in animation for page elements on scroll
- Subtle hover and transition states

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Noto Serif and Manrope
- Material Symbols for navigation icons
